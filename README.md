# ダイヤモンド監督(baseball-manager-sim)

野球チームの監督になって選手を育て,草野球リーグからプロリーグを目指すブラウザゲームです.

## 遊び方

- 1年は12か月×4週の48週です.毎週,練習メニューを選んで進めます.試合は自動で行われ(試合中の操作はありません),リーグ戦は4月〜10月に散らばって行われます.試合のない週は,練習試合を組むか,練習・休養にあてます.
- 11月にプレーオフ,そのあと全リーグが参加する全日本選手権があります.プレーオフも選手権も,毎週の進行で自分のチームの試合を行います.
- 練習は選んだ能力が重点的に伸び,それ以外の能力も少しずつ伸びます.
- 選手は練習と試合で成長します.成長タイプ(早熟,普通,晩成)と隠れた伸びしろがあります.
- 一緒に試合に出たり,守備練習・投球練習をすると,バッテリーと二遊間の連携が深まります.
- リーグが上がるほどチーム数と試合数が増えます(草野球10試合,社会人15試合,独立21試合,プロ28試合,メジャー28試合).昇格・降格するチーム数は,下のリーグほど少なく(草野球と社会人の境目と,社会人と独立の境目は1チーム,独立とプロは2チーム,プロとメジャーは1チーム)なります.
- 「チーム」タブで,能力のレーダーチャート,リーグ内の比較,成長の推移が見られます.
- 5つのリーグ(草野球,社会人,独立,プロ,メジャー)がすべて動いていて,毎シーズン同じチームと選手が続きます.「順位」タブで全リーグの順位,個人成績,歴代の優勝が見られます.
- 選手の通算成績は,「選手」タブで選手をタップすると見られます.
- 練習メニューには「おすすめ」が表示され,チームの弱点(リーグ平均との差)と練習ごとの伸びの見込みのグラフが見られます.
- 試合の結果では,戦評,ボックススコア,ドット風のアニメ再生が見られます.
- 選手には球種(投手)と特殊能力(野手・投手)があり,練習や出来事で身につきます.打線や守備の組み合わせで「コンボ」が発動します(オーダータブ).
- 年俸と年間予算があり,予算の範囲で選手を獲得・保有します.監督の信頼度は,練習の伸び,予算,自由契約の入団に効き,0になると解任されます.
- ミッションを達成して食材を集め,料理を作ると,しばらく練習の伸びが大きくなります.
- 練習や試合で疲れがたまり,怪我をすることがあります.怪我人は控えが代わりに出ます.休養や医務室で防げます.
- 入場収入や食材の売却で資金を得て,施設(スタジアム,練習場,医務室,食堂,スカウト室)を強くできます.
- 選手の詳細画面で能力の推移が見られ,守備位置のコンバートもできます.
- はじめてガイド,用語の説明(下線の言葉をタップ),文字サイズ・テーマの切り替え,難易度(やさしい/ふつう/やり込み),おまかせ進行(オーダー・休養を自動で)があります.
- 休んだほうがいいときは忠告が出ます.効果音とBGM(初期はオフ)もあります.
- シーズンの終わりに,優勝・MVP・新人王・成長した選手・資金の増減をまとめた「1年の振り返り」が出ます.
- あなたはGM(ゼネラルマネージャー)です.「チーム」タブの「スタッフ」で,監督(攻撃型・守備型・堅実型・育成型)と,打撃・投手・守備走塁・トレーナー・メンタルのコーチを雇えます.年俸は毎週,資金から払います.
- 選手の総合力と将来性は,星(★)で一目で分かります.おまかせオーダーは,実力重視・調子重視・育成重視から選べます.
- 毎週,ときどき出来事(選手の相談,トレードの打診など)が起き,選んだ結果でチームが変わります.
- 「記録」タブで,実績,ライバルとの対戦成績,表彰,引退した名選手,プロでの目標(通算5回優勝で殿堂入り)が見られます.
- シーズン後にはプレーオフ(上位4チーム),加齢,引退,ドラフト会議,自由契約(戦力外になった選手の獲得)があります.ドラフトと自由契約では,チームの弱点から「おすすめ」が表示されます.

## 開発環境

Node.js 20 以上が必要です.

```bash
npm install        # 初回のみ
npm run dev        # 開発サーバー(http://localhost:5173)
                   # VS Code では F5 でも起動できます(.vscode/launch.json)
npm test           # テスト
npm run typecheck  # 型チェック
npm run e2e        # 画面の自動テスト(スマホの画面幅で操作する)
npm run balance    # バランス確認(リーグ別の打撃成績,練習ごとの成長量,12シーズンの歩み)
npm run build      # 公開用のビルド(dist/ に出力)
```

## ディレクトリ構成

```
src/
├─ types.ts          型定義
├─ data/constants.ts リーグ,チーム名,名前リストなどの定数
├─ util/             乱数(シード対応),表示用の整形
├─ engine/game.ts    試合シミュレーション(打席,走塁,継投)
├─ growth/           選手生成,成長,加齢,練習メニュー,連携
├─ league/           チーム編成,日程,順位,シーズン進行,ドラフト
├─ save.ts           セーブとロード(localStorage)
├─ ui/               画面の描画と操作
└─ main.ts           エントリーポイント
tests/               テスト(Vitest)
scripts/balance.ts   バランス確認スクリプト
```

`engine/`,`growth/`,`league/` は DOM に依存しない純粋なロジックです.
乱数は必ず `util/random.ts` を経由させ,テストでは `setRandom(seeded(n))` で結果を固定します.

## 公開(GitHub Pages)

`main` ブランチに push すると `.github/workflows/deploy.yml` が自動でビルドして公開します.
初回だけ,GitHub のリポジトリ設定の Pages で,Source を「GitHub Actions」にしてください.
